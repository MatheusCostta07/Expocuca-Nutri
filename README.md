# 📚 Expocuca Nutri

> Um espaço dedicado à apresentação do curso técnico de Nutrição, seus projetos e realizações acadêmicas.

---

## 🎯 Sobre o Projeto

O **Expocuca Nutri** é um site informativo desenvolvido como ferramenta educacional para o curso técnico de Nutrição. Ele funciona como uma plataforma de exposição e divulgação dos conhecimentos adquiridos pelos alunos, apresentando de forma clara e organizada:

- Informações gerais sobre o curso técnico de Nutrição
- Projetos desenvolvidos pelos estudantes
- Trabalhos práticos e pesquisas realizadas
- Conteúdo educativo relacionado à área de nutrição

Este repositório reúne todo o código-fonte da aplicação, permitindo fácil manutenção, atualização e contribuição da comunidade acadêmica.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura e semântica

## 🚀 Como Usar

### Visualizar Online
Acesse o site através do link: https://matheuscostta07.github.io/Expocuca-Nutri/

### Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MatheusCostta07/Expocuca-Nutri.git
   cd Expocuca-Nutri
   ```

2. **Abra o arquivo principal:**
   - Localize o arquivo `index.html` na pasta do projeto
   - Abra-o no seu navegador web

3. **Pronto!** O site está rodando localmente na sua máquina

> Não há dependências externas ou instalações complexas necessárias.
